# 太太盤中觀察 (Spouse Intraday Check)

用於手動觸發原本應由 Windows 工作排程器在每天 09:35（開盤30分鐘確認）與 11:30（盤中觀察）自動執行的盤中通知（`spouse_intraday_check.py`）。跟 `/spouse-report`（05:00 的完整輪動報告）是獨立功能。

## 執行前提

1. 確認 `.env` 內已設定 `SPOUSE_EMAIL`（太太的收件信箱）；沒設定會直接報錯，提醒使用者先補上再執行。
2. **只有在實際交易時段（週一~週五 09:00~13:30）才會真的寄送**——`microstructure.is_trading_session_now()` 會自動判斷，非交易時段（週末、國定假日、盤前盤後）執行只會印出略過訊息，不會寄信，這是設計上的行為，不是錯誤。執行前先跟使用者確認現在是不是交易時段，避免白跑一趟。

## 執行步驟

3. `uv run python spouse_intraday_check.py`
4. 執行成功後回報：已寄送至哪個信箱，或說明「目前非交易時段，本次略過未寄送」。

## 注意事項

- 這個功能只用在太太的短線輪動觀察，跟使用者本人長期持股的月度配置決策完全無關。
- 盤中強弱評分是規則型的粗略觀察因子（開盤溢價率／30分鐘量能確認／盤中拉回幅度），**沒有經過統計驗證**，回覆使用者時記得保留這個風險提醒。
- 若只是想看今天的短線輪動族群排名（不含盤中強弱），改用 `/sector-rotation-preview`。
