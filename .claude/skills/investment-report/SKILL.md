# 投資報告 (Investment Report)

使用者要求產生／更新投資報告時，依序執行以下步驟。

## 執行步驟

1. 確認 `個人持股明細.xlsx` 存在。不存在就告知使用者並停止，這是必要輸入檔，不要代為建立或猜測內容。
2. `uv run python main.py`，會同步輸出 `投資報告.md` 與 `投資報告.xlsx`（覆寫更新，兩者都是個人財務資料，已列在 `.gitignore`，不會被上傳）。
3. 執行成功後，讀取 `投資報告.md`，用**繁體中文**在對話中摘要重點給使用者看，不要整份貼出全文，聚焦在：
   - 個人短期目標追蹤：獲利達成率、進度是否符合預期、有沒有跌破基準總市值下限
   - 總市值／總報酬率
   - 大盤（加權指數）今日表現，簡短對照投組表現
   - AI 綜合評分與行動建議：有沒有🔴（建議賣出/停損）或🟠（分批獲利了結/減碼）訊號的個股，
     極端虧損股（≤-70%）在安靜期內不算異常，不用特別提醒
   - 潛力新標的觀察：高價股/低價股候選清單裡有沒有評分特別突出的標的
   - 近期（例如未來 2 週內）有沒有法說會
   - 三大法人買賣超有沒有明顯異常（例如某檔外資大量賣超）
   - 有沒有觸發集中度風險警示（單一標的／產業佔比 ≥30%）

## 注意事項

- 這個報告會呼叫多個外部資料源（yfinance、證交所 OpenAPI、公開資訊觀測站、Google 新聞），且會額外評估約 20-25 檔候選新標的（潛力新標的觀察），執行時間可能需要 2-3 分鐘，屬正常現象，不需要中途判斷是卡住。
- 報告內容是使用者的個人財務資料，只在對話中呈現摘要，不要主動建議把 `投資報告.md`／`.xlsx` 上傳、分享或發布到任何外部平台（包含 Artifact）。
- 只是想看「今天類股輪動排名」不需要跑這個技能，改用 `/sector-rotation-preview`（更快、不含個人持股資料）。
