# 凱基連線測試 (KGI Connection Test)

**現況（2026-07-27）：凱基 API 串接已擱置**，使用者決定不再投入時間排查，持股異動改為手動維護 `個人持股明細.xlsx`（詳見 `專案進度.md` 第 33 項、README.md「凱基證券 API 串接」段落）。**這不是待辦事項，平時不要主動提起或詢問凱基連線進度**——只有使用者明確要求重新測試時，才觸發這個技能。這個技能用較高階模型，因為判讀原生層級錯誤訊息、比對是否為已知問題還是全新狀況，需要較強的推理能力，誤判會讓使用者去問凱基技術支援錯的問題。

## 執行前提

1. 確認 `.env` 內已有凱基帳密設定（`.env.example` 有欄位範本）；沒有的話提醒使用者先填寫。
2. 提醒使用者：這個測試必須在**已完成凱基憑證安裝的這台電腦**上執行才有意義（憑證是跟機器綁定的）。
3. 若在企業網域網路下測試，先提醒使用者：TradeCom 連線曾經被公司防火牆擋住（只有換到非公司網路如手機熱點才能連上），若連線逾時，先懷疑網路環境，不要急著當成憑證或元件問題。

## 執行步驟

4. `uv run python test_kgi_connection.py`
5. 讀取輸出結果：
   - 若成功（能列出可用帳號／取得報價或庫存），恭喜使用者，並詢問是否要接著把 `kgi_client.py` 接進 `portfolio.py` 取代手動 Excel 維護（先確認連線測試成功再進行這步，不要在測試通過前就先動手改主要流程）。
   - 若卡在憑證簽章 `CGPureSign... Fail!! ErrorCode = 5010`：這是目前已知、尚未解決的卡點（無公開文件），直接說明「這個錯誤碼還沒解決，需要凱基技術支援協助」，不用重新從頭排查（網路、憑證元件註冊、帳戶權限都已排除過）。
   - 若是全新的、之前沒見過的錯誤訊息，才需要重新分析並更新 `專案進度.md` 的記錄。

## 注意事項

- 這個技能只做**報價與庫存查詢**的連線測試，絕對不要嘗試呼叫下單／委託相關方法（`kgi_client.py` 依使用者指示本來就沒有實作下單功能，也不要新增）。
- Claude 沒有使用者的真實帳密，這個測試一定要由使用者本機執行，Claude 無法代為驗證帳密正確性以外的問題。
