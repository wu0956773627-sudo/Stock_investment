# 類股輪動預覽 (Sector Rotation Preview)

用於使用者只是想看看「目前類股輪動掃描結果」，但不想觸發實際寄信給太太（寄信是 `/spouse-report` 的職責）。

## 執行步驟

1. 這是唯讀、無外部副作用的任務（不寄信、不通知任何人、不寫入任何檔案），**用 Agent 工具背景執行**（`subagent_type: general-purpose`，`run_in_background: true`），派工內容為「在專案目錄執行 `uv run python sector_rotation.py`，回報完整終端機輸出」（`sector_rotation.py` 本身有 `__main__`，會印出排名前 5 強族群、每族群前 5 檔個股的買賣區間，以及跨族群依股價由低到高排序的「個股動能 Top5」）。背景執行的用意是不佔用主對話，方便跟其他技能（例如 `/investment-report`）同一回合一起觸發；若使用者只單獨要求這一個、且明確想要「馬上看結果」，這個技能通常幾十秒內就跑完，也可以直接在主對話用 Bash 執行，不強制一定要背景化。
2. 背景任務回報完成後，把輸出內容整理後回覆給使用者（保留原本的族群排名結構）。

## 注意事項

- `WATCHLIST` 是人工整理的固定台股熱門族群清單（記憶體、半導體、AI伺服器散熱、航運、金融、生技、網通、面板、綠能、重電、軍工，共11組），不是全市場掃描，若使用者問「還有沒有其他族群」，直接說明這是設計上的限制，不用重新掃描。
- 這是短線技術面規則型參考（均線＋近期高低點），不是價格預測；回覆使用者時記得保留這個風險提醒。
- 執行時常會看到個別股票的 yfinance 404／delisted 錯誤訊息（watchlist 裡部分舊代號可能已下市或代碼異動），這是已知現象，程式會自動跳過該檔繼續計算其他股票，不影響其餘結果，不需要每次都回報成「錯誤」，除非使用者要求要修 watchlist。
