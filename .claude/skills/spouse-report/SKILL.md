# 太太短線報告 (Spouse Sector-Rotation Report)

獨立於主報告之外的功能：產生「短線類股輪動觀察」並寄給使用者的太太，同時 BCC 一份給使用者本人。

## 執行前提

1. 確認 `.env` 內已設定 `SPOUSE_EMAIL`（太太的收件信箱）；沒設定會直接報錯，提醒使用者先補上再執行。

## 執行步驟

2. 寄送本身是使用者觸發這個技能時已經同意的操作，但等待寄信可能花一點時間。若使用者這回合還想在前台繼續做其他事，**用 Agent 工具背景執行**（`subagent_type: general-purpose`，`run_in_background: true`），派工內容為「在專案目錄執行 `uv run python spouse_report.py`，回報完整終端機輸出」；若使用者明確想要「馬上等結果」，直接用 Bash 前台執行 `uv run python spouse_report.py` 即可，不強制背景化。
3. 背景任務回報完成後（或前台執行完成後），回報：已寄送至哪個信箱（`SPOUSE_EMAIL`），並告知使用者本人也會收到密件副本（BCC），對方看不到有副本。

## 隱私限制（務必遵守）

- 這個報告的內容**只能是短線類股輪動觀察**（族群排名、買賣區間、預估天數），絕對不能包含使用者本人的持股明細、股數、金額、市值、損益等個人財務資料——這是這個功能誕生時使用者明確要求的界線。
- 若使用者要求把持股相關資訊加進寄給太太的內容，先跟使用者確認是否真的要打破原本「太太只看短線輪動，看不到我的持股」的設計，不要默默照做。
- 若只是想「看一下今天的輪動排名、還不想寄信」，改用 `/sector-rotation-preview`，不要為了看內容而觸發實際寄信。
